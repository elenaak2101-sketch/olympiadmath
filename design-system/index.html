Принципы экранов

1 · Поиск

Главный экран: крупная строка поиска + чипы тем. Результаты — карточки задач с подсветкой совпадений и ссылкой на страницу PDF.

2 · Сборники

Dropzone сверху, таблица индексируемых PDF со статусами. Операции над файлом — ghost-кнопки, опасные — красные.

3 · Подборки

Тренер собирает листы задач в подборки для занятий; экспорт в PDF. Акцентный оранжевый — только для «Создать подборку».

Правила стиля
  • Один primary-фиолетовый на экран; оранжевый — максимум одна акцентная кнопка.
  • Скругления: поля 6px, карточки 10px, hero/панели 16px, кнопки и чипы — pill.
  • Номера страниц и ID задач всегда моноширинным шрифтом — их копируют в конспекты.
  • Touch-target ≥ 44px сразу (мобильная версия наследует веб-компоненты).
  • Контраст текста ≥ 4.5:1; тёмная тема — через алиасы, не хардкод цветов.
