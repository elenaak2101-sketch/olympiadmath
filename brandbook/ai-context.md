# MathFinder — бренд-контекст для LLM / разработчика

> Вставляй этот файл в контекст проекта (CLAUDE.md / .cursorrules / системный промпт).
> Это сжатая версия брендбука v1.0. Источник истины по значениям: `design-system/tokens.css` и `tokens.json`.

## Продукт
Локальный веб-инструмент (позже мобильный) поиска олимпиадных задач по темам в неструктурированных PDF-сборниках для студентов техвузов. Пользователь — тренер/преподаватель математики, ежедневная работа, ценит скорость и плотность информации.

## Личность бренда
Академичный · быстрый · точный · спокойный. Не игровой, не маркетинговый. Тон: коллега-тренер, «вы» со строчной, конкретные числа (страницы, счётчики), без эмодзи-простыней и капса.

| Text | `--text-primary/-secondary/-tertiary` | Gray 900/600/500 | текст |
| Border | `--border-default/-strong` | Gray 200/300 | разделители |
| Success | bg `#CAF4E3` / text `#17976A` | — | «проиндексировано» |
| Warning | bg `#FFEFCD` / text `#C98A00` | — | «частично распознано» |
| Danger | bg `#FFCDCD` / text `#D92D20` | — | ошибки PDF |

Правила цвета:
1. Соотношение 60/30/10: нейтральные фоны / brand-soft / brand+accent. Оранжевого всегда меньше всего.
2. Текст на оранжевом — тёмный (`--gray-900`), НИКОГДА белый (контраст 2.0:1).
3. Фильтры/теги тем — серые чипы или brand-soft, не радушные цвета.
4. Тёмная тема обязательна: переключается `[data-theme="dark"]`, компоненты пишутся только через алиасы.

## Типографика
- **Inter** (400/600/700/800) — весь UI. Замена платных TildaSans/Gilroy с референсов.
- **JetBrains Mono** — номера задач `№4.2.18`, страницы `стр. 137–142`, ID, счётчики `214/214`. Никогда в беглом тексте.
- Шкала: 12 caption/badge · 14 secondary · 16 body · 18 · 20 H4 · 24 H3 · 30 H2 · 36–56 H1(hero, clamp).
- Заголовки: weight 700–800, letter-spacing −0.02em, line-height 1.2; body line-height 1.55, строка ≤70 симв.

## Геометрия
- Spacing 4px: 4·8·12·16·20·24·32·40·48·64·80·96. Никаких произвольных значений.
- Radius: `sm 6` поля/теги · `md 10` карточки · `lg 16` панели · `pill 999` кнопки/чипы/фильтры (фирменная форма).
- Shadows: xs/sm/md/lg мягкие rgba(20,20,24,…); фокус-кольцо `0 0 0 3px violet 30%` обязательно.
- Layout: container 1200, header 64, gutter 20; брейкпоинты 480/768/1024/1280; mobile-first.

## Компонентные паттерны
- **Кнопки:** pill; варианты primary(violet)/accent(orange, 1 на экран)/ghost(outline violet)/link(blue); высота ≥44px.
- **Чип темы:** pill, border gray-200; активный — violet-500 + белый текст.
- **Карточка задачи:** заголовок-условие с `<mark>`-подсветкой (bg orange-100 + underline orange-300), мета-строка mono (`стр. 137 · №4.2.18`), бейдж сложности словом (Лёгкая/Средняя/Сложная) на пастельном фоне, ссылка «Открыть в PDF».
- **Dropzone PDF:** пунктурная рамка gray-300 r-lg; hover/drag → border brand + bg brand-soft; внутри прогресс «страница 137 из 214».
- **Navbar:** белая плашка, sticky, bottom-border gray-200; активный пункт — pill brand-soft.

## Motion
120ms hover/focus · 200ms модалки/карточки · 320ms раскрытие панелей. Одна кривая `cubic-bezier(.2,.7,.3,1)`. Без пружин и overscroll.

## Доступность (обязательно)
- Контраст ≥4.5:1 для текста, ≥3:1 для крупных/иконок (см. таблицу контрастов в брендбуке).
- Смысл никогда только цветом: сложность дублируется текстом бейджа.
- Видимый фокус на всех интерактивных элементах; touch-target ≥44×44.

## Железные правила кода
1. Только токены/алиасы (`var(--brand)`, `bg-brand` в Tailwind) — хардкод HEX в компонентах запрещён.
2. Новый цвет → сначала токен в `tokens.css` + `tokens.json`, потом использование.
3. Один оранжевый CTA на экран.
4. Все размеры кратны 4px, радиусы только из шкалы.
5. Компоненты должны работать в светлой и тёмной теме без правок (только алиасы).
