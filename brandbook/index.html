01 — Позиционирование

Кто мы и для кого

🎯 Продукт

Локальный инструмент поиска олимпиадных задач по темам в неструктурированных PDF-сборниках для студентов техвузов. Индексация → извлечение задач → поиск по чипам тем.

Тренеры и преподаватели математики. Эксперты, работают каждый день, ценят скорость и плотность информации выше декора. Вечером работают в тёмной теме.

«Превращаем гору скучных PDF в мгновенный тематический поиск». Спокойный академичный инструмент, а не игровой сервис.

02 — Логотип и знак

Знак «√» в градиентном квадрате

√

radius = 30% от размера

Правила

  • Охранные поле ≥ высоте знака (∅ = 1×mark)
  • Минимальный размер: 24px в вебе, 44px в иконке приложения
  • На белом/сером фоне — как есть; на фото/тёмном — только на плашке --bg-surface или с белой подложкой
  • Градиент фиксированный 135°, направление менять нельзя

04 — Типографика

Inter + JetBrains Mono

Референсы используют платные TildaSans и Gilroy. Бесплатный аналог с отличной кириллицей — Inter. Моноширинный JetBrains Mono обязателен для технических идентификаторов: их копируют в конспекты.

Правила наборки

  • Максимум 3 веса на экран: 400 / 600 / 800
  • Заголовки — letter-spacing −0.02em, жирность 700–800
  • Не использовать ALL CAPS в заголовках (только eyebrow-метки 12px)
  • Длина строки body ≤ 70 символов

Куда идёт mono

  • №4.2.18 — номера задач
  • стр. 137–142 — диапазоны страниц
  • ID документов, хеши, счётчики формата 214/214
  • Никогда — в беглом тексте и заголовках

07 — Сетка и отступы

Шаг 4px, контейнер 1200

Spacing scale

4·8·12·16·20·24·32·40·48·64·80·96 — никаких «13px по вкусу»

Брейкпоинты и touch

sm 480 · md 768 · lg 1024 · xl 1280
container 1200 · header 64 · gutter 20

  • Mobile-first: всё, что сделано для веба, наследуется мобилкой
  • Touch-target ≥ 44×44px обязателен
  • Плотность списка задач выше, чем у маркетинговых сайтов — это рабочий инструмент

10 — В коде

Как применять брендбук при разработке

Источники истины

design-system/tokens.cssCSS-переменные, web
design-system/tokens.jsonW3C tokens → Figma / iOS / Android
brandbook/ai-context.mdсжатая версия для промптов LLM
brandbook/tailwind.preset.jspreset для Tailwind v3/v4

Железные правила

  1. В компонентах — только семантические алиасы (var(--brand)), не сырые HEX
  2. Новый цвет? Сначала добавить токен, потом использовать
  3. Оранжевый = максимум одна кнопка на экран
  4. Размеры кратны 4px; радиусы только из шкалы
  5. Изменения токенов — через PR с апдейтом этого брендбука
Для LLM-кодера: подключите файл brandbook/ai-context.md в контекст проекта (или вставьте в системный промпт) — он содержит все правила на ~1 странице.
